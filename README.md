# Sistema de Ventas — Demo

Demo pública e interactiva de una plataforma comercial para cotizaciones y ventas.

**Stack:** React 19, TypeScript, Vite y CSS.

## Funcionalidades

- Dashboard con indicadores y ritmo comercial.
- Creación de cotizaciones con carrito, descuento e IGV.
- Listado con búsqueda, duplicación, eliminación y conversión a venta.
- Catálogo de productos ficticios.
- Datos persistidos en `localStorage` del navegador.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Publicación

El proyecto se despliega en GitHub Pages desde la rama `main` y la carpeta `dist/`.

> Todos los clientes, productos, documentos y ventas son ficticios.
